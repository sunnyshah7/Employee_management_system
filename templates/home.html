This is a Django web application project named "Pour". It is designed to provide users with a platform to share and discover various drink recipes. The project aims to create a community where users can contribute their favorite recipes, rate them, and leave comments.

The main features of the Pour project include:

  • User registration and authentication
  • Recipe submission and management
  • Search functionality to find specific recipes
  • Rating and commenting system for user feedback
  • Responsive design for mobile and desktop users

The project is built using Django, a high-level Python web framework that encourages rapid development and clean, pragmatic design. The front-end is developed using HTML, CSS, and JavaScript to ensure a user-friendly interface.

We welcome contributions from the community to help improve the Pour project. If you have any suggestions or would like to contribute, please feel free to reach out!
